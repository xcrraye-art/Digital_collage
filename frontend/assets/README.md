# 宝石素材与图案

`polished-gems.png` 为本项目通过图像生成工具制作的第二版宝石图集（1402 × 1122 RGBA），模拟珠宝摄影；不是实拍照片，也未提取参考游戏素材。五列依次为祖母绿、玫红宝石、石榴石、黄水晶、海蓝宝，四行依次为圆形、水滴、马眼形、心形。`polished-atlas.json` 记录主体像素裁切。背景包含半透明柔光，绘制时以主体路径裁切，不把背景或阴影当作宝石轮廓。

`geometry.json` 保存六幅固定排布。原版四幅及其主体轮廓保留，以兼容现有 v3 存档。两幅精修作品使用 atelier 前缀的解析曲线路径；贴图遮罩、凹槽、点击命中共用这条路径，凸包用于保守间距检查。水滴、马眼、心形保留各自切形。

`gemstones.png` 与 `atlas.json` 为第一版素材，保留给原版生成器使用。当前运行时使用第二版图集。`scripts/layouts.py` 生成四幅原版；随后运行 `scripts/atelier.py` 追加两幅精修图并校验至少 1.8 画布单位的主体间距，不改变原版坐标。后者需要 Pillow 读取透明度，不修改图集图片。

`python3 scripts/bundle.py` 将当前图集、裁切表、几何数据嵌入单文件 HTML。运行游戏不需要图片服务、Python 或后端。

# 宝石素材

`gemstones.png` 是本项目使用图像生成工具制作的原创透明宝石图集（1402 × 1122 RGBA），不是从参考视频提取的素材。

五列分别为祖母绿、玫红宝石、石榴石、黄水晶、海蓝宝；四行分别为圆形、水滴、马眼形、心形。图像模拟珠宝微距摄影的光学质感，不是实拍照片或物理光线追踪。

`atlas.json` 记录各宝石在标准化 500 × 400 图集坐标中的裁切区域（含少量透明边距），与 app.js 中的裁切表一致。渲染时通过 SVG symbol/use 选择区域，保留原 PNG。

单文件版本通过 scripts/bundle.py 把同一图集嵌入 HTML，无需网络素材服务。

`geometry.json` 是新版实际使用的主体轮廓、自然宽高比、主体裁切区域和四幅固定贴画坐标。`scripts/layouts.py` 从原 PNG 的高透明度主体区域提取轮廓，排除半透明阴影；不修改原 PNG。槽位、纹理和点击区域使用同一份轮廓。几何排布保守使用凸包碰撞检测并保留至少1.3单位主体间距。

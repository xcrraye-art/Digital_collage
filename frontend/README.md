# 宝石花园 · Gem Garden

纯前端宝石贴画小游戏。使用原生 HTML、CSS、JavaScript、Canvas2D 与本地透明宝石纹理，手机和电脑都能玩。

## 运行

在仓库根目录执行：

```sh
cd frontend
python3 -m http.server 8000 --bind 0.0.0.0
```

也可直接打开 `gem-garden.html`。多文件版本需保留 `assets/` 目录。单文件版已嵌入纹理与排布数据，无需在线素材服务或后端。

## 玩法

打开后先选择贴画，进入白色画布。选图页中，未开始的贴画展示成品预览；已开始的贴画展示真实已贴进度和进度条，可以继续完成。顶部按“颜色＋切割形状”选择宝石，按照独立编号点击贴放；同色的圆形、水滴形、马眼形和心形分别编号和统计，选错形状也不能贴放。连贴模式按住划过多个同编号凹槽；移动模式拖动画布，拖动范围受限；停止操作后若画面中没有宝石，会找回附近区域，避免画布被拖丢。手机支持双指捏合，电脑支持滚轮，也可使用按钮缩放（70%～800%）。支持撤销、重来、可选音效和自动保存。撤销会退回上一次点击或整段连贴，并回到那次操作对应的宝石类型。选色栏显示每种宝石的剩余数量，当前类型的凹槽会略微加深以便辨认。

找不到小颗宝石时，点击“找一颗”，会定位并放大当前颜色的一颗未完成宝石，以轮廓圈出；定位本身不会贴放。点击“全图”恢复视图。手机在点击模式下长按未完成凹槽约半秒，可直接选中所需的颜色与形状；长按松手不会自动贴放。宝石种类较多时可滑动选色栏，自动切换类型或长按取样后会把当前类型滚到可见位置。滚轮以鼠标位置为中心缩放，手机点击模式下明显滑动不会在松手时误贴。横屏时选色栏移到左侧，操作栏保留在画布下方。

选图页优先展示两幅精修作品：翡翠花冕181颗、双鸟花枝397颗。花冕采用对称花瓣与规则细珠圈；双鸟采用沿羽毛方向的水滴行列和小圆钻头部。原版作品收在“原版作品 · 继续以前的贴画”中，可继续原进度。宝石材质升级、凹槽阴影减轻，游戏顶部和工具区压缩，扩大白色画布。

原版四幅贴画：翡翠花冠140颗、春日枝语103颗、繁星花海175颗、相依的鸟儿210颗。主宝石沿花瓣、叶脉与羽毛排列，剩余空间用小颗填补。生成阶段检查轮廓边界与主体间距，旋转后的主体不会相互重叠。

## 绘制与几何

`assets/geometry.json` 保存固定排布、素材主体裁切与真实轮廓。纹理、白色凹槽、碰撞与点击命中共用这一份轮廓；保持素材自身的宽高比例。通过透明度阈值提取宝石主体，排除半透明接触阴影。运行时将细小轮廓台阶平滑成曲线，保留主要切割尖角；平滑后的同一条路径用于贴图遮罩、凹槽与点击判定，且保持在原凸包内，沿用已校验的排布间距。

材质与凹槽在加载时预绘制成可复用图片；默认使用一张场景缓存，贴放与撤销只更新局部。缩放/移动按动画帧合并；手势期间用缓存预览，停下后在高倍率下按可见范围重绘清晰素材和编号。没有逐颗 SVG 元素或常驻闪光动画。

拖动命中使用空间网格和真实轮廓。连贴利用浏览器可用的合并触控采样，补齐最后移动点到松手点的线段，并先裁切屏幕外的笔画；快速划过时减少漏颗。进度增量统计，存档在笔画结束或350毫秒短延迟后写入，离开页面时补写。切到后台时提交当前笔画并释放触摸状态，恢复后可直接操作。闪光最多同时8个；减少动态效果偏好下关闭。

## 存档

新版使用 `gem-garden-v3-*` 存档键。由于位置、数量和编号已改变，新版贴画从零开始；原 `gem-garden-*` 旧版存档仍保留，未覆盖或删除。精修版使用独立的 atelier 作品 ID；原四幅保持宝石的位置、索引和 v3 存档键，现有 v3 进度继续保留。清除浏览器数据会删除存档，跨设备不会自动同步。

## 开发和验证

修改页面、样式、逻辑或数据后，从仓库根目录运行：

```sh
python3 scripts/bundle.py
```

单文件版由该脚本生成，不需要手动维护两套代码。

重新生成主体几何和固定排布（开发工具需要 Pillow；运行游戏无需 Python 包）：

```sh
python3 scripts/layouts.py
python3 scripts/atelier.py
python3 scripts/bundle.py
```

生成器对所有宝石进行最终全量碰撞复核，主体间距至少1.3画布单位。心形使用凸包进行保守检查，因此其凹口不会被自动填满。

云环境已有 Playwright 和 Chromium，可执行浏览器回归：

```sh
node tests/smoke.cjs
```

其他机器需提供 Playwright 和 Chromium，可用 `GEM_BROWSER_BIN` 指定浏览器路径。测试覆盖六幅贴画（含精修版贴放与存档）、颜色匹配、命中、撤销、连贴、存档与旧存档保留、重置、完成提示、放大后命中、单文件版、手机点击/双指缩放及高分屏尺寸。还覆盖同色不同形状拦截、11种宝石滚动栏、长按取样不贴放、整段连贴撤销、定位不自动贴放、鼠标缩放锚点稳定、滑动防误触、横屏控制区域与定位后贴放。还验证连贴松手终点、画布拖动边界与找回、后台笔画清理及实际进度缩略图。触摸模拟不替代真机手感测试。

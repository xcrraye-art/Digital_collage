# 宝石花园 · Gem Garden

纯前端宝石贴画小游戏。使用原生 HTML、CSS、JavaScript、Canvas2D 与本地透明宝石纹理，手机和电脑都能玩。

## 运行

在仓库根目录执行：

```sh
cd frontend
python3 -m http.server 8000 --bind 0.0.0.0
```

也可直接打开 `gem-garden.html`。多文件版本需保留 `assets/` 目录。单文件版已嵌入纹理与排布数据，无需在线素材服务或后端。

## 玩法

打开后先选择贴画，进入白色画布。顶部选择宝石，按照编号点击贴放；连贴模式按住划过多个同编号凹槽；移动模式拖动画布。手机支持双指捏合，电脑支持滚轮，也可使用按钮缩放（70%～800%）。支持撤销、重来、可选音效和自动保存。

四幅贴画已重新排布：翡翠花冠140颗、春日枝语103颗、繁星花海175颗、相依的鸟儿210颗。主宝石沿花瓣、叶脉与羽毛排列，剩余空间用小颗填补。生成阶段检查轮廓边界与主体间距，旋转后的主体不会相互重叠。

## 绘制与几何

`assets/geometry.json` 保存固定排布、素材主体裁切与真实轮廓。纹理、白色凹槽、碰撞与点击命中共用这一份轮廓；保持素材自身的宽高比例。通过透明度阈值提取宝石主体，排除半透明接触阴影。

材质与凹槽在加载时预绘制成可复用图片；默认使用一张场景缓存，贴放与撤销只更新局部。缩放/移动按动画帧合并；手势期间用缓存预览，停下后在高倍率下按可见范围重绘清晰素材和编号。没有逐颗 SVG 元素或常驻闪光动画。

拖动命中使用空间网格和真实轮廓。进度增量统计，存档在笔画结束或350毫秒短延迟后写入，离开页面时补写。闪光最多同时8个；减少动态效果偏好下关闭。

## 存档

新版使用 `gem-garden-v3-*` 存档键。由于位置、数量和编号已改变，新版贴画从零开始；原 `gem-garden-*` 旧版存档仍保留，未覆盖或删除。清除浏览器数据会删除存档，跨设备不会自动同步。

## 开发和验证

修改页面、样式、逻辑或数据后，从仓库根目录运行：

```sh
python3 scripts/bundle.py
```

单文件版由该脚本生成，不需要手动维护两套代码。

重新生成主体几何和固定排布（开发工具需要 Pillow；运行游戏无需 Python 包）：

```sh
python3 scripts/layouts.py
python3 scripts/bundle.py
```

生成器对所有宝石进行最终全量碰撞复核，主体间距至少1.3画布单位。心形使用凸包进行保守检查，因此其凹口不会被自动填满。

云环境已有 Playwright 和 Chromium，可执行浏览器回归：

```sh
node tests/smoke.cjs
```

其他机器需提供 Playwright 和 Chromium，可用 `GEM_BROWSER_BIN` 指定浏览器路径。测试覆盖四幅贴画、颜色匹配、命中、撤销、连贴、存档与旧存档保留、重置、完成提示、放大后命中、单文件版、手机点击/双指缩放及高分屏尺寸。触摸模拟不替代真机手感测试。

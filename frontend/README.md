# 宝石花园 · Gem Garden

无需构建或安装依赖的纯前端宝石贴画小游戏。使用原生 HTML、CSS、JavaScript、SVG 与本地透明宝石纹理，适配手机、平板与电脑。

## 本地运行

在仓库目录执行：

```sh
cd frontend
python3 -m http.server 8000 --bind 0.0.0.0
```

也可直接打开 `gem-garden.html`。这个单文件包含样式、脚本及宝石素材，不需要在线素材服务。多文件版本需要一并保留 `assets/`。

## 玩法

打开后先选择贴画，点击画作进入白色画布，通过“返回选图”切换其他画作。顶部选择宝石，点击相同编号的凹槽。点击模式逐颗放置；连贴模式按住拖动连续贴放当前颜色；移动模式拖动画布。

手机支持双指捏合缩放；电脑支持鼠标滚轮；也可使用缩放按钮。放大倍率为 70% 至 800%，点击“适应画布”恢复位置和倍率。

四幅原创图案：翡翠花冠（45 颗）、春日枝语（67 颗）、繁星花海（217 颗）、相依的鸟儿（650 颗，含心形宝石）。宝石采用五种颜色、圆形/水滴/马眼/心形四种切割的写实图集，配合白色内陷凹槽、贴放闪光和柔和阴影。

每幅画自动保存进度到当前浏览器 localStorage；原有三幅画的存档编号保持兼容。清除浏览器数据会移除存档。支持撤销当前会话的贴放、重置及可选音效。不需要账号或后端。

## 修改与验证

更改 HTML/CSS/JS 或图集后，从仓库根目录运行：

```sh
python3 scripts/bundle.py
```

重新生成自包含的 `frontend/gem-garden.html`。无需手动维护两套代码。

云环境已有 Playwright 和 Chromium，可在仓库根目录运行：

```sh
node tests/smoke.cjs
```

其他机器需自行提供 Playwright 与 Chromium；可用 `GEM_BROWSER_BIN` 指定 Chromium 的可执行路径。测试自动启动并停止自己的临时 HTTP 服务，验证素材、选图、贴放、错误颜色拦截、撤销、存档、连贴、完成、双鸟、手机触摸缩放与单文件版。触摸模拟无法替代真机手感检查。

素材来源与图集坐标见 `assets/README.md`。写实材质为图像生成工具制作，不是实拍宝石，也不进行实时物理光线追踪。

# 宝石与拼画画面重做

本轮重做宝石图集、凹槽质感与页面样式。原版四幅保留位置、索引与存档键，移至选图页的可展开区域；新增两幅独立精修作品。

- 翡翠花冕：181颗，对称水滴花瓣、圆钻与马眼内圈、规则细金珠圈。
- 双鸟花枝：397颗，水滴羽毛行列、小圆钻头部、心形装饰与连续枝条。
- 解析曲线同时用于凹槽、材质裁切和点击；离线保守凸包碰撞复核，最小主体间距1.8画布单位。
- 第二版图集由图像生成工具制作，模拟珠宝摄影，深色内部、少量白色反光；并非实拍或物理渲染。四种切形有各自材质。
- 白色画布，轻浅凹槽，减轻接触阴影；收紧标题与工具区，保留已有缓存绘制方式。

截图由实际游戏页面在桌面1440×1050和手机模拟390×844（DPR2）下截取。成品图和手机部分进度图使用预置本地存档以展示画面；实际贴放、类型匹配、撤销和存档另由 tests/smoke.cjs 验证。手机模拟不能替代真机手感测试。
